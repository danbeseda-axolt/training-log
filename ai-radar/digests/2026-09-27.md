# AI Radar — 2026-09-27

**TL;DR:** The cost of frontier AI fell again this week. Claude Opus 5.5 and OpenAI's GPT-6 Sol/Luna are both cheaper than the models they replace, and Klaviyo now exposes 260+ MCP tools, so Claude or ChatGPT can run real Klaviyo work, not just answer questions about it. Also: if your team uses Wispr Flow, its Notetaker turns on for every organisation on 30 Sep unless an admin disables it first.

## 🔥 Don't miss

### 1. Claude Opus 5.5 — top Claude model, cheaper and faster than Opus 5
**What:** Released 22 Sep. Anthropic says it performs at the level of Claude Fable 5.1 on most work. It has a 1M-token context window and costs $4 / $20 per million input/output tokens, down from $5 / $25 for Opus 5. Reviewers measure it at over 30% faster.
**Why it matters:** You already use Claude and Claude Code every day, so this upgrades your default model and lowers the cost. Long agent runs that re-read the same context (support macros, product catalogues, codebases) benefit most, since cache reads cost $0.20/M. Reviewers put the saving at around 40% for cache-heavy work and 20–33% for typical workloads.
**Try it:** Pick it in the Claude model picker or in Claude Code. If you call the API directly, reviewers list four API behaviours that break when moving from Opus 5, so test before you switch any automation.
**Sources:** [release notes](https://releasebot.io/updates/anthropic) · [review](https://www.eesel.ai/blog/claude-opus-5-5-review) · [breaking changes](https://codingfleet.com/blog/claude-opus-5-5-review/)

### 2. Klaviyo MCP — 260+ tools that let AI agents run Klaviyo
**What:** Klaviyo added more than 260 MCP tools. Claude, OpenAI or a custom agent can now read data, build segments, run campaigns, write flows and manage catalogues in your account. A ready-made Klaviyo connector is in Anthropic's MCP Directory. Released in September 2026; exact date unconfirmed.
**Why it matters:** Email and SMS are a core revenue channel for Axolt. You can now go from "ask Claude about last month's flows" to "have Claude build the segment and draft the flow" without leaving the chat. The analytics agent also now covers 365 days of data.
**Try it:** Add the Klaviyo connector in Claude (Settings → Connectors). Start with read-only questions, then let it draft (not send) a campaign.
**Sources:** [Klaviyo docs](https://developers.klaviyo.com/en/docs/klaviyo_mcp_server) · [release notes](https://releasebot.io/updates/klaviyo) · [field guide](https://everboost.co.uk/insights/klaviyo-mcp-server/)

### 3. GPT-6 Sol and Luna — OpenAI's cheaper everyday and bulk models
**What:** Released 22 Sep in ChatGPT Work, Codex and the API. Sol is for demanding everyday work at $2 / $10 per million tokens. Luna is for high-volume tasks at $0.10 / $0.50. Both sit below the flagship GPT-6 Astra (released 3 Sep). Free and Go users can try Luna in the desktop app.
**Why it matters:** Luna's price makes bulk jobs almost free: tagging thousands of support tickets or reviews, classifying Fairing/Zigpoll survey answers, rewriting product descriptions. They aren't in regular ChatGPT Chat; you find them in Work and Codex.
**Try it:** On Plus or above, open ChatGPT Work or Codex and select Sol. For bulk jobs, run Luna through the API.
**Sources:** [OpenAI announcement](https://community.openai.com/t/announcing-gpt-6-sol-and-gpt-6-luna-in-the-api-codex-and-chatgpt/1399925) · [TechCrunch](https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/)

## 💡 One idea to steal
Set up a weekly **Klaviyo flow check-up** in Claude with Opus 5.5. Connect the Klaviyo and Shopify connectors, then ask: *"Pull the last 30 days of flow performance, rank flows by revenue per recipient against the previous 30 days, flag the 3 biggest drops, and draft two subject-line and first-block variants for each. Don't send or publish anything."* Keep it read-and-draft for the first few weeks. Once you trust the output, let it create the A/B tests as drafts for you to approve. Then save the prompt as a Claude skill so anyone on the team can run it.
